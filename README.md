# Two Number Swapper 🔄

A simple C program that swaps the values of two integers using a temporary variable.

## 🚀 Features
- Takes two integer inputs from the user (`A` and `B`).
- Displays values before and after swapping.
- Clean, basic algorithm suitable for standard logic practice.

## 🛠️ How to Compile & Run

### Using Dev-C++ (Windows)
1. Open Dev-C++.
2. Go to `File` > `Open` and select `​number-swapper.cpp`.
3. Press `F11` (or click `Execute` > `Compile & Run`).
